# 사진 편집기 (photo-editor)

브라우저에서 바로 쓰는 **단독 사진 편집기**. 설치 없이 열면 바로 편집할 수 있고, 사진은
**서버로 전송되지 않습니다** — 모든 처리는 브라우저 Canvas 안에서만 이루어집니다.

🔗 <https://anchirong9-arch.github.io/photo-editor/>

휴대폰(390px)과 PC(1440px) 모두에서 같은 화면 구성으로 동작합니다.

## 기능

**사진**
- 로컬 파일 선택 · 드래그&amp;드롭 · 클립보드 붙여넣기(Ctrl+V)
- 여러 장을 동시에 불러와 **슬롯**으로 보관하고 클릭해서 교체 (편집 내용 유지/초기화 선택)
- EXIF 회전 정보 자동 반영

**자르기 · 변형**
- 자유 / 1:1 / 4:5 / 9:16 / 16:9 / 3:4 비율 프리셋, 모서리 핸들 드래그, 삼분할 가이드
- 90° 회전, 좌우 · 상하 반전

**색감 · 필터**
- 밝기 · 대비 · 채도 · 색온도(따뜻/차갑) · 비네팅 · 흐림(블러) 슬라이더
- 원클릭 프리셋 9종 — 원본, 선명, 필름, 흑백, 따뜻, 시원, 레트로, 페일, 생생
- ‘원본 비교’ 버튼을 누르고 있는 동안 보정 전 화면

**자유 텍스트 (여러 레이어)**
- 추가 · 수정 · 복제 · 삭제, 캔버스에서 직접 드래그 이동 / 모서리로 크기 / 동그라미로 회전
- 폰트 8종 (블랙한산스, 노토산스, 주아, 도현, 나눔손글씨 펜, 고운바탕, 고운돋움, 나눔명조) — 모두 저장소에 내장
- 글자색 · 굵기 · 기울임 · 자간 · 행간 · 정렬 · 줄바꿈 폭 · 불투명도
- **컬러 테두리**(색 + 두께), **컬러 그림자**(색 + 불투명도 + 번짐 + X/Y), **배경 박스**(색 + 둥글기 + 여백 + 투명도)

**모자이크 · 그리기 · 도형**
- 드래그 영역 픽셀 모자이크 / 블러 (강도 조절, 여러 영역)
- 펜 · 형광펜 · 지우개, 색상·두께·불투명도
- 사각형 · 원 · 화살표 (선 색·두께·채우기·불투명도)

**실행 취소 &amp; 저장**
- Undo / Redo (최대 60단계), 레이어 숨기기·순서 변경
- PNG · JPG · WebP 선택, 품질 조절, 원본 해상도(또는 긴 변 2560/1920/1080)로 내보내기
- 모바일에서는 공유 시트로 바로 보내기

## 인스타 · 쓰레드 링크로 불러오기 (집 PC 연동)

웹(HTTPS)에서는 인스타그램·쓰레드가 CORS·로그인으로 막혀 있어 게시물을 직접 열 수 없습니다.
그래서 집 PC의 **백수톡 스튜디오**가 대신 링크를 열어 사진을 넘겨 주는 구조입니다.

- 앱: 상단 **🔗 링크** → 링크 붙여넣기 → `POST http://localhost:8770/api/extract-media`
- 스튜디오가 꺼져 있으면 “집 PC에서 백수톡 스튜디오를 실행하면 링크에서 원본 사진을 바로 불러올 수 있습니다”
  안내와 함께 **사진 파일 열기** 버튼을 보여 줍니다.
- 주소가 다르면 모달의 *고급 · 스튜디오 주소*에서 바꿀 수 있습니다(브라우저에 저장).

### 스튜디오에 필요한 엔드포인트 규격

```http
POST /api/extract-media
Content-Type: application/json

{ "url": "https://www.instagram.com/p/..." }

200 { "ok": true, "images": [
      { "url": "http://localhost:8770/api/media/ab12.jpg", "width": 1080, "height": 1350, "name": "인스타 1" },
      { "dataUrl": "data:image/jpeg;base64,..." }
    ] }
```

- `images` / `items` / `media` 배열, 또는 배열 자체를 그대로 돌려줘도 됩니다.
- 항목은 `url` · `dataUrl` · `base64` 중 아무거나 — `base64`만 주면 앱이 `data:image/jpeg;base64,`를 붙입니다.
- CORS 헤더가 필요합니다:
  `Access-Control-Allow-Origin: https://anchirong9-arch.github.io` (또는 `*`),
  `Access-Control-Allow-Methods: POST, OPTIONS`, `Access-Control-Allow-Headers: Content-Type`,
  `Access-Control-Allow-Private-Network: true`, `OPTIONS` 프리플라이트에 204 응답.
- `GET /api/health` → 200 (없어도 동작하지만 있으면 연결 상태가 더 정확합니다)

## 구조

```
index.html          화면 뼈대
styles.css          다크 스튜디오 UI (모바일 390px 대응)
js/state.js         편집 상태 · 레이어 모델 · 히스토리
js/render.js        Canvas 렌더 파이프라인 (필터 · 텍스트 · 모자이크 · 도형)
js/editor.js        캔버스 크기 · 포인터 제스처 · 자르기 · 내보내기
js/ui.js            패널 · 컨트롤 바인딩
js/boot.js          시작점
assets/fonts/       내장 웹폰트 (OFL, Google Fonts / Fontsource)
```

외부 서버·CDN 호출이 없습니다. 폰트까지 저장소에 들어 있어 오프라인에서도 동일하게 동작합니다.
